# Clinical Safety

## Genel

Teşhis, tedavi, ilaç dozu, bireysel reçete yok. Dil korkutucu/utandırıcı olmamalı.

## Gate’ler

| Durum | Davranış |
|---|---|
| <18 yaş | Yetişkin BMI/RMR/TDEE/hedef kilo kapalı → çocuk aracına veya “uygun değil” |
| Gebelik/emzirme | Zayıflama hedefi yok; D02 bilgilendirme |
| Çok düşük BMI / hızlı istemsiz kayıp | Uyarı + profesyonel yönlendirme |
| Diyabet | C05 sadece CHO toplamı; **insülin yok** |
| Sıvı kısıtı | B06 “hekim kısıtı varsa uygulama” |
| Yeme bozukluğu riski | Hedef kilo / kısıtlayıcı dil yok |

## Blocked araçlar

- **MUST (D03):** BAPEN izni olmadan ölçek kopyalanmaz.  
- **MNA-SF (D05):** Telif; resmi kaynağa link.

## Veri

Hesaplar tarayıcıda; varsayılan kayıt yok (KVKK).
